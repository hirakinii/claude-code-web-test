# ソフトウェア仕様書作成アプリ

ソフトウェア開発プロジェクトの仕様書を簡単に作成・管理できるWebアプリケーションです。

## 機能

### 1. 仕様書の項目
以下の項目を記入できます：

- **件名** - プロジェクトの件名
- **調達の背景** - なぜこの調達が必要なのか
- **調達の目的** - 調達によって達成したい目標
- **納品物** - 成果物の詳細
- **納品場所** - 成果物を納品する場所
- **納品期限** - 納品の期限日
- **調達の種別** - 準委任または委任から選択
- **調達のスコープ** - コンサルティング、要件定義支援、機能設計、機能開発から複数選択可能
- **受注者に求められる要件** - 受注者が満たすべき条件
- **業務の基本要件** - プロジェクトの基本的な要求事項
- **各業務のタイトルと詳細仕様** - 個別の業務タスクとその詳細

### 2. 自動日付入力
新規作成時に、作成日が自動的に設定されます。作成日は「年月日」形式で表示されます。

### 3. バージョン管理
- バージョン番号はインクリメント形式（例：1.0.0 → 1.0.1）で付与されます
- 「バージョンを更新する」ボタンをクリックすることでバージョンが更新されます
- バージョン情報は画面上部に常時表示されます

### 4. データの自動保存
- 入力内容は自動的にブラウザのローカルストレージに保存されます
- ページをリロードしても、入力データは保持されます

### 5. エクスポート機能
以下の形式でエクスポート可能です：

- **Markdown形式** - .md ファイル
- **PDF形式** - .pdf ファイル
- **Word形式** - .docx ファイル

## 使い方

### 1. アプリケーションの起動

ブラウザで `index.html` を開くだけで使用できます。ローカルサーバーを使用する場合：

```bash
# Python 3の場合
python -m http.server 8000

# Node.jsのhttp-serverを使用する場合
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセスします。

### 2. 仕様書の作成

1. 各フィールドに必要な情報を入力します
2. 「業務を追加」ボタンで業務タスクを追加できます
3. 入力内容は自動的に保存されます

### 3. バージョンの更新

「バージョンを更新する」ボタンをクリックすると、バージョン番号が自動的にインクリメントされます。

### 4. エクスポート

目的の形式に応じたエクスポートボタンをクリックします：

- **Markdownでエクスポート** - テキストエディタで編集可能な形式
- **PDFでエクスポート** - 印刷や配布に適した形式
- **Wordでエクスポート** - Microsoft Wordで編集可能な形式
